# Python Learning Docs

This directory keeps the staged Python learning notes.

The documents use Java as the comparison baseline because the target reader already knows Java, Spring Boot, technical components, and distributed system patterns.

Use the docs and code together:

1. Read the stage document.
2. Run the matching module in `src/iron_python_learning/stages`.
3. Debug the module and compare Python behavior with the Java mental model.
4. Extract reusable ideas into real packages only after the concept is stable.
